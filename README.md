# J. S. S. II — 재능 격파 시뮬레이터

GitHub Pages에서 바로 실행 가능한 정적 웹게임 프로토타입입니다.

## 실행 방법

1. `index.html`을 브라우저로 열면 바로 실행됩니다.
2. GitHub Pages 배포 시 저장소 루트에 `index.html`을 올리고 Pages를 활성화하면 됩니다.
3. 서버는 필요하지 않으며 저장 데이터는 브라우저 `localStorage`에 저장됩니다.

## 조작

- PC 이동: 마우스 이동 또는 드래그
- 모바일 이동: 터치 드래그
- 출격: `Space` 또는 우측 작전 콘솔의 `출격`
- 일시정지: `Esc`
- 파워업 선택: 카드 클릭 또는 숫자키 `1~3`

## 구현 범위

- 상단 UI: 로고 / J. S. S. II / 재능 격파 시뮬레이터
- 통합 콘솔: 작전, 상태, KU 강화, 아티팩트, 스킬트리, 경전, 기록, 도움말

- 플레이어 HP 삭제, 보호막 없으면 즉사
- 적 하단 통과 피해 없음

- 무기 4종: 전방 탄환, 측면 탄환, 미사일, 레이저
- 10종 파워업 및 무기 가중치 랜덤

- 노드형 스킬트리
